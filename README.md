## 🛠️ Tools & Their Uses

### 🔐 WHOIS
![WHOIS](https://img.shields.io/badge/WHOIS-4B0082?style=for-the-badge)

Used to find domain registration details such as **registrar, creation date, and expiry date**. This helps identify domain ownership and registration information.

### 🌐 WhatWeb
![WhatWeb](https://img.shields.io/badge/WhatWeb-0066CC?style=for-the-badge)

Used to identify **web technologies** running on the target site. This can help identify software that may have known vulnerabilities.

### 🔎 Nslookup
![Nslookup](https://img.shields.io/badge/Nslookup-008000?style=for-the-badge)

Used to resolve **domain names to IP addresses**, helping determine where the website is hosted.

### 📡 cURL
![cURL](https://img.shields.io/badge/cURL-555555?style=for-the-badge&logo=curl&logoColor=white)

Used to inspect **HTTP headers**, revealing information about server software, caching mechanisms, and security headers.

### 🧱 Wafw00f
![Wafw00f](https://img.shields.io/badge/Wafw00f-FF8C00?style=for-the-badge)

Used to detect whether a **Web Application Firewall (WAF)** is present and identify the security technology protecting the web application.

### 🗂️ DNSRecon
![DNSRecon](https://img.shields.io/badge/DNSRecon-8A2BE2?style=for-the-badge)

Used for **DNS enumeration**, exposing information such as nameservers, mail servers, TXT records, and other DNS records.

### 🖥️ Zenmap / Nmap
![Nmap](https://img.shields.io/badge/Nmap-1679A7?style=for-the-badge&logo=nmap&logoColor=white)

Used to scan networks for **live hosts and open ports**, helping identify active devices and potential entry points.
